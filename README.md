## How I Plan to Document Projects

Each project should make it easy to understand:

1. **The objective** — the question or problem being investigated.
2. **The environment** — the setup, tools, and relevant assumptions.
3. **The process** — the steps taken and the reasoning behind them.
4. **The results** — observations, evidence, and limitations.
5. **The lessons** — what worked, what failed, and what to improve next.

Troubleshooting is part of that process. A failed experiment can be useful when its cause and lessons are documented clearly.
